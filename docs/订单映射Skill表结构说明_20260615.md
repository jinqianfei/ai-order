> 涉及表数：7 张 | 总记录数：5,321 条

## 表概览

| 表名 | 记录数 | 用途 | Skill 中的角色 |
|------|--------|------|----------------|
| store_list | 3,327 | 门店列表 | 门店匹配（6层） |
| product_sku | 1,832 | SKU主表 | SKU匹配（6层） |
| product_name_alias | 30 | 商品名别名 | SKU Layer 0 别名匹配 |
| warehouse_code_mapping | 113 | 仓库编码映射 | 模板生成时取仓库编码 |
| order_feedback | 19 | 订单反馈 | 自学习模块数据源 |
| order_corrections | 0 | 纠正记录 | 自学习模块纠正数据 |
| layer_success_rate | 14 | 匹配层成功率 | 自学习模块效果评估 |

---

## 核心流程与表的关系

```
订单输入
  │
  ├─ Step 1: 解析订单（LLM）
  │
  ├─ Step 2: 门店匹配 ──→ 查 store_list（6层匹配）
  │     └─ 用户确认后 → 记录 order_feedback
  │
  ├─ Step 3: SKU匹配 ──→ 查 product_sku + product_name_alias（6层匹配）
  │     └─ 用户确认后 → 记录 order_feedback + order_corrections
  │     └─ 更新 layer_success_rate
  │
  ├─ Step 4: 生成模板 ──→ 查 warehouse_code_mapping（取仓库编码）
  │
  └─ 输出华鼎31字段出库单Excel
```

## 1. store_list — 门店列表（3,327 条）

## 2. product_sku — SKU主表（1,832 条）

> SKU匹配的核心数据源，合并了原 system_sku 和 shipper_sku_mapping 两张表

| 字段 | 类型 | 必填 | 含义 |
|------|------|------|------|
| id | integer | ✅ | 主键，自增 |

| customer_code | varchar | ❌ | 货主自编码 |
| sku_name | varchar | ✅ | 商品名称（匹配主键） |
| product_spec | varchar | ❌ | 包装规格（如"12瓶/件"） |
| unit | varchar | ✅ | 基本单位（件/瓶/箱/桶等） |

| shipper_id | varchar | ✅ | 货主ID（唯一约束 part2，按货主过滤） |
| category | varchar | ❌ | 品类/存储方式 |
| warehouse_code | varchar | ❌ | 默认仓库编码 |
| status | varchar | ❌ | 状态（ACTIVE等） |
| created_at | timestamp | ❌ | 创建时间 |

**唯一约束**: (sku_code, shipper_id) — 同一SKU编码可被多个货主使用

## 7. layer_success_rate — 匹配层成功率（14 条）

> 自学习模块：统计每个匹配层（门店6层 + SKU6层）的成功率，用于评估和优化

| 字段 | 类型 | 必填 | 含义 |
|------|------|------|------|
| id | integer | ✅ | 主键，自增 |
| entity_type | text | ❌ | 实体类型（store/sku） |
| layer_name | text | ❌ | 匹配层名称（如 Layer 0、Layer 1） |
| layer_description | text | ❌ | 匹配层描述 |
| total_attempts | integer | ❌ | 该层总尝试次数 |
| success_count | integer | ❌ | 用户直接确认（无修改）次数 |
| auto_success_count | integer | ❌ | 自动确认（相似度>=90%）次数 |
| user_corrected_count | integer | ❌ | 被用户纠正次数 |
| success_rate | numeric | ❌ | 成功率（success + auto_success / total） |
| avg_match_score | numeric | ❌ | 平均匹配分数 |
| updated_at | timestamp | ❌ | 更新时间 |

**唯一约束**: (entity_type, layer_name) — 每个实体类型的每个匹配层只有一行统计

### 索引

| 索引名 | 字段/用途 |
|--------|-----------|
| layer_success_rate_entity_type_layer_name_key | 唯一约束 (entity_type, layer_name) |
| idx_layer_entity | entity_type |
