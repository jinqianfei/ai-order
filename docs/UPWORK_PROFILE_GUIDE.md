## 三、Profile 优化技巧

### 1. 头像
- 清晰正脸，占画面 60%+
- 浅色/纯色背景
- 微笑，看起来可信任
- 不要用证件照（太正式）或生活照（太随意）

### 2. 标题
- 说清楚你是做什么的 + 一个数字亮点
- "AI Supply Chain Automation Developer" 比 "Python Developer" 好 10 倍

### 3. 前两行最重要
- 客户搜索时只看 Overview 前 2 行
- 所以我写了 "I build AI agents that automate supply chain operations. Not just chatbots — production-grade systems..."
- 第一句说定位，第二句建立信任

### 4. 证书
- 如果有 AWS / Azure / Google Cloud 证书，加上
- 没有也没关系，你的项目经验比证书值钱

Hi [name],

For [brief mention of their specific need], I'd approach it by:

Quick question: [一个澄清问题，证明你认真看了需求]

Here's a similar system I built: [link to portfolio]

Best,
Jin
```

### 模板 B：Python 自动化/脚本类项目

```
Hi [name],

I specialize in Python automation for supply chain and logistics — I've built everything from order processing pipelines to multi-agent MCP systems. Happy to knock this out quickly.

Your project looks straightforward. A couple of thoughts:
1. [你的理解]

One question before I dive in: [澄清问题]

Can deliver in [timeline]. Here's a related project: [portfolio link]

Best,

### 模板 C：AI Agent / Chatbot 类项目

```
Hi [name],

I build production AI agents, not just chatbots. My current system includes 43 MCP tools with multi-agent orchestration and self-learning feedback loops.

For your use case, I'd recommend:
1. [方案建议]
2. [技术选型]

I've built similar systems for customer service, order processing, and lead generation. Happy to share examples.

Quick question: [澄清问题]

Best,
Jin
```

### Proposal 黄金法则

| 法则 | 说明 |
|------|------|
| **前 2 行定生死** | 客户预览只看到前 2 行，必须在这 2 行内展示"我做过这个" |
| **必须问一个问题** | 每个 Proposal 末尾问一个具体问题，这会迫使客户回复你 |
| **不要用模板感** | 每个 Proposal 都要改 2-3 处针对该项目的具体内容 |
| **不要提价格** | Proposal 里不谈价格，等客户回复后再谈 |
| **不要长篇大论** | 100-150 词足够，长了没人看 |
| **附上作品链接** | 每次投递都附上相关的 Portfolio 项目链接 |

## 八、投递策略

### 每天流程（30 分钟）

```
1. 打开 Upwork → Find Work
2. 依次搜索以下关键词（每个搜一遍）：
   - supply chain automation
   - inventory management system
   - Python automation script
   - Excel automation data processing
   - AI agent chatbot customer service
   - API integration workflow automation
   - n8n automation workflow
   - data processing Python

3. 筛选条件：
   ✅ Verified Payment（绿色盾牌图标）
   ✅ 发布 24 小时内
   ✅ 已有 Proposal 数 < 20（太多竞争，新号没机会）
   ✅ 客户有历史评价（说明不是僵尸号）

4. 对每个匹配的项目，花 2-3 分钟写一个定制 Proposal
5. 每天投 5-10 个
```

### 前 3 天重点关注

| 项目类型 | 预算 | 优先级 | 原因 |
|---------|------|--------|------|
| Python 脚本/自动化 | $50-200 | ⭐⭐⭐ | 最容易拿首单，交付快 |
| Excel 数据处理 | $50-150 | ⭐⭐⭐ | 竞争小，你擅长 |
| API 集成/工作流 | $100-300 | ⭐⭐ | 单价高一点 |
| Supply Chain 相关 | $200-500 | ⭐⭐⭐ | 你最核心的领域 |
| AI Agent/Chatbot | $200-500 | ⭐⭐ | 长期价值高 |

### 不要投的

| 类型 | 原因 |
|------|------|
| 预算 < $50 | 不够你的时间成本 |
| 已投 50+ proposals | 客户大概率不看了 |
| 需求模糊（"I need a website"） | 浪费沟通时间 |
| 客户 0 历史评价 | 可能是骗子 |
| 要求 24 小时内交付（除非很简单） | 风险太高 |
| 需要特定时区/语言（你做不到的） | 浪费时间 |

### 首单策略

- **目标**：2 周内拿到 3 个 5 星评价
- **方法**：接 2-3 个小单（$50-200），超预期交付
- **超预期**：多做一个 bonus feature（比如加个简单的 Web 界面、写个文档），让客户惊喜
- **交付后**：礼貌地请客户给 5 星评价
  ```
  "If you're happy with the work, a 5-star review would mean a lot —
  it's my first few projects on Upwork and I'm building my reputation. Thanks!"
  ```
