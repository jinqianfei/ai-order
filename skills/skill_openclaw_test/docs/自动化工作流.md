# Skill 自动化测评与修复工作流

## 概述

本框架实现「测评 → 风险分级 → 自动修复 → 复测 → 部署」的完整自动化闭环。

## 核心组件

| 组件 | 文件 | 职责 |
|------|------|------|
| 测评框架 | `skill_openclaw_test/` | 执行 Skill 测评，输出结构化报告 |
| 风险分级 | `config/risk_levels.yaml` | 定义高风险/普通风险/禁止修复规则 |
| 自动修复 | `scripts/auto_repair.py` | 根据风险分级决定是否自动修复 |
| Git备份 | `scripts/auto_repair.py` (GitBackupManager) | 修复前打分支，失败后回滚 |
| 工作流编排 | `scripts/workflow.py` | 串联整个流程 |

## 工作流程

```
人工触发
    ↓
┌─────────────────────────┐
│  1. 自动化测评          │ ← skill_openclaw_test
│     输出量化报告         │
│     包含问题清单         │
└─────────────────────────┘
    ↓
┌─────────────────────────┐
│  2. 风险分级判断        │ ← risk_levels.yaml
│     高风险 → 暂停       │ ← 需人工确认
│     普通风险 → 自动修复  │
└─────────────────────────┘
    ↓
┌─────────────────────────┐
│  3a. 高风险路径         │
│     人工审查代码改动     │
│     人工确认后继续       │
└─────────────────────────┘
    ↓
┌─────────────────────────┐
│  3b. 普通风险路径        │
│     Git 创建备份分支     │
│     执行自动修复        │
│     复测验证            │
└─────────────────────────┘
    ↓
┌─────────────────────────┐
│  4. 复测对比            │ ← 与原报告对比
│     改善 → 合并 Git      │ ← 自动同步 EC2
│     回归 → 回滚 Git      │
└─────────────────────────┘
    ↓
    完成
```

## 风险分级规则

### 高风险（必须人工确认）
- 数据库 Schema 变更（ALTER/CREATE/DROP）
- 核心匹配算法逻辑变更（Layer 0-3）
- 数据库连接配置变更
- API 签名变更
- 删除已有功能

### 普通风险（自动修复）
- 新增可选字段
- 错误信息优化
- 日志增强
- 类型注解补充
- 代码格式调整

### 禁止自动修复
- 密码/密钥相关代码
- 网络请求代码
- 数据删除操作
- 依赖变更

## 快速开始

### 方式1：命令行执行

```bash
# 测评
python skills/skill_openclaw_test/scripts/run_evaluation.py \
  --skill-path ../skill_order_to_huading_template \
  --db-config ../config/db_config.yaml \
  --test-data ../test_data \
  --output ../docs/测评报告.md

# 修复（干跑）
python skills/skill_openclaw_test/scripts/auto_repair.py \
  --skill-path ../skill_order_to_huading_template \
  --report ../docs/测评报告.md \
  --action dry_run

# 修复（执行）
python skills/skill_openclaw_test/scripts/auto_repair.py \
  --skill-path ../skill_order_to_huading_template \
  --report ../docs/测评报告.md \
  --action execute

# 回滚
python skills/skill_openclaw_test/scripts/auto_repair.py \
  --skill-path ../skill_order_to_huading_template \
  --action rollback \
  --target-branch main
```
